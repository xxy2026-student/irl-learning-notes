# Latent-Dynamics-Conditioned Flow Policy — discussion page

A single-page research presentation for advisor discussion:
**From Marginal Multimodality to Environment-Conditioned Imitation.**

## Run

Open `webpage/index.html` in any modern browser (an internet connection is
needed once, for MathJax and the two Google fonts; everything else is local).

## Files

| file | role |
| --- | --- |
| `index.html` | all content and math (MathJax `tex-svg`, loaded from cdnjs) |
| `style.css`  | typography, layout, figure styling, reveal animations |
| `script.js`  | SVG figures (densities, flow transport, schematics), the point-mass toy simulation, progress bar / dot rail / keyboard navigation |

## Navigation

`↑` `↓` `PgUp` `PgDn` move one section per keystroke; `Home` / `End` jump to
the ends; the right-hand dot rail is clickable; the top hairline shows reading
progress.

## Content policy

The page distinguishes standard background from our own claims: everything
beyond textbook material is explicitly labeled *Goal*, *Hypothesis*,
*Research question*, or *Illustration* — nothing is presented as an
established result. The section-08 animation is a conceptual simulation of
the toy dynamics stated on the page, not an experiment.
